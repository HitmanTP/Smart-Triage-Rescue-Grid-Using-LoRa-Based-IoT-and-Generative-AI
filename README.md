# Smart-Triage-Rescue-Grid-Using-LoRa-Based-IoT-and-Generative-AI
A 100% off-grid, self-healing communication ecosystem for disaster management. Integrates LoRa mesh networking, autonomous "Man Down" detection (TinyML), and AI-driven medical triage (Ollama) to optimize rescue operations in communication dark zones. Developed for SIH 2025 (Problem ID 25122).
